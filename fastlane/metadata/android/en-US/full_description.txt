OpenThumb shows the state of your Android phone at a glance and helps you fix what it finds with AI.

Phone check
• Open the app and it reads storage, security patch and battery health into one score.
• It lists the apps that can read your screen or notifications, and any device admin apps.
• The check needs no API key and stays on your phone.

Fix it
• Tap Fix it on any item and the AI looks into the cause and suggests what to do.
• It asks before each step that changes anything.

AI helper
• Bring your own API key for Claude, GPT, Gemini and others.
• It works in a Linux sandbox inside the app, using Python to sort files and do the math.
• Run tasks at set times.
• When a notification matches your rule, the AI drafts a reply. By default nothing is sent until you approve it.

Privacy
• No account, no analytics, no server of ours.
• Your API key and conversations go only to the AI provider you set up.

OpenThumb is free and open source (GPL-3.0), built on OpenMinis.
Source: https://github.com/neulketing/openthumb

오픈썸은 안드로이드 폰의 상태를 한눈에 보여 주고, 문제를 AI와 함께 고치는 앱입니다.

내 폰 점검
• 앱을 열면 저장 공간, 보안 패치, 배터리 상태를 읽어 점수로 보여 줍니다.
• 화면이나 알림을 읽을 수 있는 앱, 기기 관리자 앱을 목록으로 보여 줍니다.
• 점검은 API 키 없이 폰 안에서만 이루어집니다.

고쳐 줘
• 항목의 「고쳐 줘」를 누르면 AI가 원인을 살펴보고 방법을 제안합니다.
• 무언가를 바꾸기 전에 단계마다 확인을 구합니다.

AI 도우미
• Claude, GPT, Gemini 등 쓰시는 AI의 API 키를 넣어 사용합니다.
• 앱 안의 리눅스 샌드박스에서 Python으로 파일을 정리하고 계산합니다.
• 정해 둔 시간에 작업을 실행합니다.
• 규칙에 맞는 알림이 오면 AI가 답장 초안을 만듭니다. 기본 설정에서는 승인하기 전까지 보내지 않습니다.

개인정보
• 계정이 없고, 분석 도구가 없고, 우리 서버가 없습니다.
• API 키와 대화는 직접 설정한 AI 제공사로만 전송됩니다.

오픈썸은 무료 오픈소스 앱(GPL-3.0)이며 OpenMinis를 바탕으로 만들었습니다.
소스 코드: https://github.com/neulketing/openthumb
